# Ascendant Equipment

Ascendant Equipment is a Minecraft 26.2 (NeoForge) mod.

## Status

Currently in early development (`0.0.0-beta.1`). Not yet feature complete.

## Requirements

| Component | Version |
|---|---|
| Minecraft | 26.2 |
| NeoForge | 26.2.0.32-beta |
| Java | 21+ |

## Installation

1. Install [NeoForge](https://neoforge.net/) for Minecraft 26.2.
2. Download the mod jar and place it in your `mods/` folder.
