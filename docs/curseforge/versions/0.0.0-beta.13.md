<h2>v0.0.0-beta.13 - Creative Mode Tab Fix</h2>

<h3>Critical Bugfix</h3>
<ul>
<li><strong>Issue</strong>: Creative Mode tab remained empty despite all items being registered. Players could not access any equipment in Creative Mode.</li>
<li><strong>Fix</strong>: Implemented <code>TabFillingRegistry</code> integration to populate the Ascendant: Adventure tab with all 49 mod items.</li>
</ul>

<h3>What's Fixed</h3>
<ul>
<li>✅ Creative Mode tab now displays all mod items</li>
<li>✅ All textures render correctly (no magenta missing textures)</li>
<li>✅ 49 items grouped by category:
  <ul>
  <li>Rarity materials (Mysterious Scrap Metal, Timeworn Fabric, Luminous Crystal Shard, Arcane Sands, Godforged Pearl)</li>
  <li>Gems and gem-related items (Gem, Gem Dust, Gem Fused Slate)</li>
  <li>Sigils (Socketing, Withdrawal, Rebirth, Enhancement, Unnaming, Malice, Supremacy)</li>
  <li>Workstation tables (Reforging, Salvaging, Augmenting, Gem Cutting, Gem Case)</li>
  <li>Special items (Boss Summoner, Potion Charm, Music Discs)</li>
  <li>Spawner runes (17 variants for different spawner modifications)</li>
  </ul>
</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Added <code>TabFillingRegistry</code> integration from <code>common_toolkit</code> library</li>
<li>Imported <code>com.skd.commontoolkit.tabs.TabFillingRegistry</code> in <code>AscendantEquipment.java</code></li>
<li>Items now properly registered to tab via constructor using <code>TabFillingRegistry.register()</code></li>
<li>No additional client setup required (uses shared event bus system)</li>
</ul>

<h3>Requirements</h3>
<ul>
<li>Minecraft: 1.26.2</li>
<li>NeoForge: 26.2.0.37-beta or later</li>
<li>Java: 21+</li>
</ul>
