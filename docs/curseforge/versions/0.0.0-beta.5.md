<h2>v0.0.0-beta.5 - Full i18n + load-order cycle fix</h2>

<p>Completes translations for all four languages and fixes the dependency floor required to resolve the startup crash caused by Ascendant Spawners beta.5/6.</p>

<h3>Localization</h3>
<ul>
<li>Full translations for <code>en_us.json</code>, <code>es_es.json</code>, <code>fr_fr.json</code> and <code>de_de.json</code>.</li>
<li>389 keys per language covering affixes, gems, items, blocks, UI, tooltips, advancements and modifiers — coverage improved from 17% to 100%.</li>
</ul>

<h3>Fix</h3>
<ul>
<li>Ascendant Spawners floor raised to <code>[0.0.0-beta.7,)</code>: earlier betas declared a reciprocal <code>ordering="AFTER"</code> toward this mod, forming a mutual ordering cycle that NeoForge cannot topologically sort (<code>Mod Sorting failed. Detected Cycles</code>) and prevented the client from starting.</li>
<li>Compile/runtime dependency in <code>libs/</code> updated to Ascendant Spawners beta.7.</li>
</ul>
