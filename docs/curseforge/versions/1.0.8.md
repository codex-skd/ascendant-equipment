<h2>v1.0.8 - Gem Case Data Loss Fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Gem Case / Ender Gem Case data loss</strong>: Both blocks required the "correct tool" to drop anything when broken, exactly like an ore mined without a pickaxe -- breaking one with the wrong tool (or bare hands) destroyed the block with <strong>zero drops</strong>, permanently deleting every gem stored inside. Removed the tool requirement so these containers always drop and preserve their contents, matching vanilla chests and barrels.</li>
</ul>

<blockquote>If you lost gems to this bug before updating, unfortunately they cannot be recovered -- this update only prevents it from happening again.</blockquote>
