<h2>v1.2.1 - Transparent Gems Feature</h2>

<h3>Change</h3>
<ul>
<li><strong>Transparent gems for unowned items:</strong> gems in the Gem Case that the player does not own now render partially transparent to distinguish them from owned gems, improving the visual experience when opening the gem chest.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Modified `GemCaseScreen.renderSlotContents()` to render unowned gems using `PipelinedRenderer.ghostFakeItem()`, which applies the ghost alpha tier for transparency.</li>
<li>Gems the player owns render normally; gems they don't own appear semi-transparent.</li>
</ul>

<blockquote>
<strong>Note:</strong> This release adds visual transparency distinction for unowned gems in the Gem Case GUI. All players should update to ensure proper gem visualization.
</blockquote>
