<h2>v0.0.0-beta.3 - Critical fix: the mod now actually loads</h2>

<blockquote><strong>0.0.0-beta.1 and 0.0.0-beta.2 never actually loaded in game.</strong> Both were missing their <code>META-INF/neoforge.mods.toml</code> file due to a build path mismatch, and NeoForge rejected the jar as "not a valid mod file". If you tried either of those versions and it didn't load, this is why - update to this version.</blockquote>

<h3>Fix</h3>
<ul>
<li><strong>Critical</strong>: fixed the build script path mismatch that caused every previous jar to ship without a valid <code>neoforge.mods.toml</code>. Verified against a live game log that the mod now loads correctly.</li>
</ul>

<h3>Metadata</h3>
<ul>
<li>Declared CurseForge project relations so the CurseForge App can auto-install required dependencies: Common Toolkit, Ascendant Attributes, Ascendant Spawners, Ascendant Enchanting and Vellumli (required), plus JEI, Jade, Max Health Fix and Enchantment Descriptions (optional, matching upstream Apotheosis's own optional companions).</li>
</ul>
