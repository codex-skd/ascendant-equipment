<h2>v0.0.0-beta.3 - JEI NPE fix (socketing recipe)</h2>

<p>Fixes a <code>NullPointerException</code> raised while JEI builds the <code>ascendant_equipment:socketing</code> recipe display. No gameplay, dependency or loader-version changes.</p>

<h3>Fix</h3>
<ul>
<li><strong><code>NullPointerException: Trying to access unbound value: empty:empty</code></strong>: <code>AffixItemIngredient.getItems()</code> called <code>getRarity()</code> unconditionally to build JEI's fake display items, which throws when the underlying <code>DynamicHolder&lt;LootRarity&gt;</code> is the unbound <code>empty:empty</code> sentinel. Guarded with <code>rarity.isBound()</code>, returning an empty item stream instead of throwing.</li>
</ul>
