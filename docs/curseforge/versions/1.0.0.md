<h2>v1.0.0 - First Stable Release</h2>

<p>Ascendant Equipment leaves beta. This release closes out the accumulated beta.15–beta.22 fixes plus a full pass on gem and socketing tooltips.</p>

<h3>Fix</h3>
<ul>
<li><strong>Gem tooltips</strong>: added the 21 missing gem name translations, all <code>gem_class.*</code> and <code>loot_category.*</code> category labels, and every gem bonus description (<code>durability</code>, <code>bloody_arrow</code>, <code>leech_block</code>, <code>all_stats</code>, <code>mageslayer</code>, <code>multi_attribute</code>) — these previously showed the raw untranslated key instead of readable text.</li>
<li><strong>Potion Charm</strong>: the item name now includes the active potion effect, and the missing tooltip lines (applied effect, source, enabled/disabled state, Curios-only notice) were added.</li>
<li><strong>Right-click-to-socket message</strong> now correctly names the gem and the target item instead of showing a blank message.</li>
<li><strong>Critical</strong>: dynamic registry codec dispatchers (LootRule, SpawnCondition, EntityModifier, GemBonus) are now initialized — rarities, gems, affixes, invaders, elites and augments all load correctly.</li>
<li>JEI recipe extensions (Malice, Supremacy, Unnaming) no longer crash on an empty rarity list.</li>
<li>Config sync no longer crashes on world join; all network payloads are properly registered.</li>
<li>Item textures and asset paths normalized (<code>textures/blocks/</code> → <code>textures/block/</code>, <code>textures/items/</code> → <code>textures/item/</code>).</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Mixin annotation processor wired into the build for refmap generation.</li>
<li><code>EquipmentEvents</code>/<code>AscEqMobEvents</code> registered on the NeoForge event bus.</li>
</ul>
