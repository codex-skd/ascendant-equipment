<h2>v1.2.2 - Potion Charm / Regalia Slots API fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Potion Charms could not be placed in the Regalia Slots API "charm" slot:</strong> the port shipped the entity file (<code>data/ascendant_equipment/curios/entities/player_charm.json</code>, which grants the "charm" slot to the player) but omitted the item-tag file that upstream Apotheosis ships (<code>data/curios/tags/item/charm.json</code> with <code>apotheosis:potion_charm</code>). The <code>regalia_slots_api:tag</code> validator on the "charm" slot only accepts items present in <code>#regalia_slots_api:charm</code>, <code>#regalia_slots_api:curio</code>, <code>#curios:charm</code> or <code>#curios:curio</code>; <code>ascendant_equipment:potion_charm</code> was in none of them, so the slot appeared but rejected the charm.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Added <code>src/main/resources/data/curios/tags/item/charm.json</code> containing <code>ascendant_equipment:potion_charm</code> (<code>required: false</code>), mirroring the upstream Apotheosis file format.</li>
</ul>

<blockquote>
<strong>Note:</strong> Data-only change. A world reload or restart is enough for the datapack tag to take effect; no client-side update logic is involved.
</blockquote>
