<h2>v0.0.0-beta.10 - Item Model Namespace Fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Item Model Namespace</strong>: Fixed all 77 item model JSON files and blockstate definitions to reference textures from the <code>ascendant_equipment:</code> namespace instead of <code>apotheosis:</code>. Items are now visible in-game with correct textures and models.</li>
<li><strong>Asset References</strong>: Updated all block models, blockstates, and item definitions to point to the correct namespace for proper asset loading.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>All model definitions now reference <code>ascendant_equipment:items/</code> and <code>ascendant_equipment:block/</code> paths correctly.</li>
<li>Blockstate and model parent references updated for consistency across the mod.</li>
<li>Items now render with their proper textures instead of missing/placeholder models.</li>
</ul>

<h3>Impact</h3>
<ul>
<li>Items that were previously invisible or showing missing texture errors will now display correctly.</li>
<li>All 49+ items, blocks, and their variants are now fully visible and functional in-game.</li>
<li>Complete asset compatibility with NeoForge 26.2 client and server.</li>
</ul>

<blockquote>
<strong>Important:</strong> This is a critical bug fix. All players should update immediately to see items and blocks in the game. Without this fix, the mod registers items in code but they are invisible due to missing model/texture references.
</blockquote>
