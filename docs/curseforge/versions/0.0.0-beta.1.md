<h2>v0.0.0-beta.1 - Port to Minecraft 1.21.1</h2>

<p>First beta of Ascendant Equipment for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21). The full Apotheosis-style equipment overhaul, same as the 26.2 build.</p>

<h3>About this build</h3>
<ul>
<li><strong>Re-fork</strong>: the 26.2 fork tree with every 26.2-only Minecraft/NeoForge API reverted to 1.21.1, using upstream <a href="https://www.curseforge.com/minecraft/mc-mods/apotheosis">Apotheosis</a> 1.21 (v8.7.0, Shadows_of_Fire / Stormraven Studios, MIT) as the 1:1 reference.</li>
<li><strong>Feature set</strong>: rarity tiers, the affix framework and effects, sockets and gems (cutting / storage / bonuses), reforging / salvaging / augmenting, loot integration, elite/invader mobs, boss spawners, gear sets, world-gen features, the Vellumli-powered guide book, commands and networking.</li>
<li><strong>Dependencies</strong>: Common Toolkit (<code>0.0.0-beta.3+</code>), Ascendant Attributes, Ascendant Spawners, Ascendant Enchanting (<code>0.0.0-beta.2+</code>), Vellumli &mdash; all required. Regalia Slots API (<code>0.0.0-beta.5+</code>), JEI and Jade are optional.</li>
<li><strong>Not built</strong>: the Gateways optional-compat package (no Gateways release to depend on), same as the 26.2 line.</li>
</ul>

<h3>Notes</h3>
<blockquote>Install all five required dependencies on both client and server. MIT licensed (upstream Stormraven copyright kept in <code>LICENSE</code>); all in-game assets are original to this project. Verified: <code>./gradlew build</code> and <code>./gradlew runServer</code> load cleanly (0 FATAL, 0 data-parse errors); not yet play-tested in a client.</blockquote>
