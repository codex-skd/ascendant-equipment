<h2>v1.1.0 - Config Persistence, Regalia Slots API, and NeoForge 26.2.0.57</h2>

<h3>Change</h3>
<ul>
<li><strong>NeoForge Update</strong>: updated from 26.2.0.45-beta to 26.2.0.57.</li>
<li><strong>Real config persistence</strong>: the adventure module config (bosses, augmenting, spawners, curios, quality of life, etc) is now actually loaded from and saved to <code>config/ascendant/equipment/ascendant_equipment.cfg</code>. Previously this file was never generated and the mod silently ran on in-memory defaults only.</li>
<li><strong>Curios &#8594; Regalia Slots API</strong>: the "charm" accessory slot now depends on our own <code>regalia_slots_api</code> (a compatible fork of Curios API) instead of the third-party Curios mod.</li>
</ul>
