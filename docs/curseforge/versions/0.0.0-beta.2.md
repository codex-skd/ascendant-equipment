<h2>v0.0.0-beta.2 - Full port compiles</h2>

<p>The mod now builds end to end for the first time: all of Apotheosis's data-driven content (affixes, gems, rarities, recipes, loot tables, tags, villager trades) and its in-game guide book have been ported, and the optional JEI/Jade integrations now compile against real NeoForge 26.2 builds.</p>

<h3>Content</h3>
<ul>
<li>All data-driven content ported: affixes, gems, rarities, purity weights, tier augments, recipes, loot tables, loot modifiers, villager trades, advancements, tags, damage types, data maps, jukebox songs, painting variants and biome modifiers.</li>
<li>In-game guide book ported from Patchouli to <strong>Vellumli</strong> (English only for now).</li>
<li>Block/item models, blockstates, particle definitions and the sound registry ported.</li>
<li>Ghost/gray item preview render effect (used when previewing socketed gems and sigils) is now functionally complete, including its shader code.</li>
</ul>

<h3>Dependencies</h3>
<ul>
<li><strong>Required</strong>: Common Toolkit, Ascendant Attributes, Ascendant Spawners, Ascendant Enchanting and Vellumli (in-house replacements for Placebo, Apothic Attributes, Apothic Spawners, Apothic Enchanting and Patchouli).</li>
<li><strong>Optional</strong>: JEI and Jade integrations now compile against real NeoForge 26.2 builds (soft dependency, same as upstream Apotheosis).</li>
<li>Gateways integration is not available for NeoForge 26.2 yet and is excluded from this build.</li>
</ul>

<blockquote>This is still an early development build: original textures, models, sounds and dungeon/tower structures have not been added yet. Placeholder/missing visuals are expected. Not save-safe across future betas.</blockquote>
