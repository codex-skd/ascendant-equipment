<h2>v0.0.0-beta.11 - Item Registration Conflict Fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Item Loading Failure</strong>: Fixed critical issue where no items were loading due to conflicting registration systems in <code>AscendantEquipment.java</code>. The mod had both <code>AscEq.R</code> (DeferredHelper) and empty <code>DeferredRegister.Items</code> competing for registration, causing complete item load failure.</li>
<li><strong>Registry Initialization</strong>: Removed conflicting scaffolding DeferredRegisters (BLOCKS, ITEMS, CREATIVE_MODE_TABS) that were interfering with the primary <code>AscEq.R</code> registration system.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Removed empty <code>DeferredRegister.Blocks BLOCKS</code>, <code>DeferredRegister.Items ITEMS</code>, and <code>DeferredRegister&lt;CreativeModeTab&gt; CREATIVE_MODE_TABS</code> from scaffolding.</li>
<li>Removed example items (EXAMPLE_BLOCK, EXAMPLE_ITEM, EXAMPLE_BLOCK_ITEM, EXAMPLE_TAB) that depended on removed registers.</li>
<li>Simplified constructor to use only <code>AscEq.bootstrap(modEventBus)</code>, matching the Apotheosis original pattern exactly.</li>
<li>Cleaned up unused imports related to removed registration code.</li>
</ul>

<h3>Impact</h3>
<ul>
<li>All 49+ items and blocks now load and register correctly on startup.</li>
<li>Item registration behavior is now identical to Apotheosis original.</li>
<li>Complete item functionality restored: equipment, affixes, gems, sigils, and all mod content are now available.</li>
</ul>

<blockquote>
<strong>Critical:</strong> This fix resolves a game-breaking item load failure. All players must update to play. Without this fix, the mod does not provide any items or blocks in-game.
</blockquote>
