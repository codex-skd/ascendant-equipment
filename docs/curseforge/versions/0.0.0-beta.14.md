<h2>v0.0.0-beta.14 - Asset Loading Fix</h2>

<h3>Critical Bugfix</h3>
<ul>
<li><strong>Issue</strong>: Item textures failed to load, displaying magenta missing-texture patterns. Models loaded correctly but asset pipeline did not include manual resources.</li>
<li><strong>Fix</strong>: Updated Gradle build configuration to explicitly include <code>src/main/resources</code> in asset processing. Added duplicate handling strategy for proper resource merging.</li>
</ul>

<h3>What's Fixed</h3>
<ul>
<li>✅ All item textures now render correctly</li>
<li>✅ Asset files (models, textures, blockstates) properly included in build</li>
<li>✅ Creative Mode tab displays items with correct textures</li>
<li>✅ All 49 mod items display with proper appearance</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Added <code>srcDir('src/main/resources')</code> to <code>sourceSets.main.resources</code> configuration in build.gradle</li>
<li>Implemented <code>duplicatesStrategy = 'include'</code> for processResources task to handle assets from both source and generated directories</li>
<li>Ensures proper processing of:</li>
  <ul>
  <li>Item models (<code>models/item/*.json</code>)</li>
  <li>Item textures (<code>textures/items/*.png</code>)</li>
  <li>Block models and textures</li>
  <li>Blockstates</li>
  <li>Other asset definitions</li>
  </ul>
</ul>

<h3>Build Requirements</h3>
<ul>
<li>Minecraft: 1.26.2</li>
<li>NeoForge: 26.2.0.37-beta or later</li>
<li>Java: 21+</li>
</ul>
