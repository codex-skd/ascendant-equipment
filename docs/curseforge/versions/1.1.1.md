<h2>v1.1.1 - Tower Chest Loot Table Fix</h2>

<h3>Fixed</h3>
<ul>
<li><strong>Tower chests generating empty</strong>: all four tower structure variants (<code>tower_leaf</code>, <code>tower_main</code>, <code>tower_sand</code>, <code>tower_spruce</code>) had their chest's <code>LootTable</code> tag pointing to <code>apotheosis:chests/tome_tower</code>, a leftover from the original Apotheosis export that was never renamed. Since this mod does not depend on Apotheosis, the loot table never resolved, logging <code>does not exist or could not be loaded</code> and leaving the chest empty. Repointed to the mod's own <code>ascendant_equipment:chests/tome_tower</code> loot table.</li>
</ul>

<blockquote>Only affects newly generated towers after updating. Towers already built in an existing world keep the broken reference baked into their chunk and are not retroactively fixed by this update.</blockquote>
