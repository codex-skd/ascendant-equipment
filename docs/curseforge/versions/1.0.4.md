<h2>v1.0.4 - World Tier map tooltip fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>World Tier map</strong>: hovering a tier icon (Haven, Frontier, Ascent, Summit, Pinnacle) on the mountain map never showed its tooltip. The screen recreated all buttons on every <code>init()</code> call instead of only the first time, and the tooltip queue for these buttons wasn't being honored by the screen's split render pipeline; both are now fixed.</li>
</ul>
