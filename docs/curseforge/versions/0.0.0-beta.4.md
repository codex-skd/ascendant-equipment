<h2>v0.0.0-beta.4 - Assets: textures, sounds and boss structures</h2>

<p>This release adds the binary assets that the mod's blockstates, item models, particle effects, sound registry and worldgen referenced but did not yet ship with. No gameplay logic changed.</p>

<h3>New Assets</h3>
<ul>
<li><strong>Textures (169)</strong>: block textures for the reforging/salvaging/gem cutting/augmenting tables and gem cases, item textures for every item (sigils, spawner runes, gems, music discs, smithing templates, the boss summoner, potion charms and more), GUI sprites and overlays, rarity beam/glow/shadow textures, particle glow, paintings and the advancement background.</li>
<li><strong>Sounds (10)</strong>: reforging table interactions, malice invocation, the four invader spawn tiers and the three music discs (flash, glimmer, shimmer) — all wired through the existing <code>sounds.json</code> registry.</li>
<li><strong>Boss structures (5)</strong>: the <code>boss_1.nbt</code> boss dungeon and the four tower variants (<code>tower_main</code>, <code>tower_leaf</code>, <code>tower_sand</code>, <code>tower_spruce</code>) used by the boss dungeon and tower worldgen features.</li>
</ul>

<h3>Build</h3>
<ul>
<li><strong>Reproducible builds on fresh clones</strong>: compile/runtime dependencies were moved from the gitignored <code>lib_ext/</code> directory to the versioned <code>libs/</code> directory. The JARs for Common Toolkit, Ascendant Attributes, Ascendant Spawners, Ascendant Enchanting, Vellumli, JEI and Jade are now committed, so a clean checkout builds without manually restoring jars.</li>
</ul>

<p>No changes to gameplay logic or data since 0.0.0-beta.3.</p>
