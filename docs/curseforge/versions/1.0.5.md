<h2>v1.0.5 - World Tier lock tooltip content fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>World Tier map lock tooltip</strong>: hovering a locked tier icon showed generic placeholder text ("Tier Locked", "Incomplete x5") instead of the tier name, the advancement to complete, and the real per-criterion checklist (e.g. "Equip a Common Chestplate"). The translation entries were missing their <code>%s</code> substitution, so the game silently dropped the dynamic text. Restored to match the original mod's format.</li>
<li>Added the 4 missing tier-name translation keys (Frontier, Ascent, Summit, Pinnacle) — only Haven had one, so those tiers had no name to show.</li>
</ul>
