<h2>v1.2.0 - Guide Book: Vellumli Migration, Spanish Translation &amp; First-Join Gift</h2>

<h3>Feature</h3>
<ul>
<li><strong>Guide book fully migrated from Patchouli to Vellumli</strong>: the "Chronicle of Shadows" book previously depended entirely on the real Patchouli mod, which wasn't even a declared dependency of this mod (it only "worked" in test packs that happened to have Patchouli installed for other reasons). Ported the 5 remaining languages (ja_jp, pt_br, tr_tr, uk_ua, zh_cn) to the new Vellumli system, removed all old Patchouli content, and fixed the recipe to depend on Vellumli instead.</li>
<li><strong>Spanish translation for the guide book</strong>: all 126 content files, plus the name/subtitle/landing translation keys.</li>
<li><strong>Guide book given on first join</strong>: every player now receives it automatically the first time they log in (survives death/reconnect). If lost afterward, it has to be crafted again (book + gold ingot).</li>
</ul>

<h3>Fix</h3>
<ul>
<li><strong>Guide book missing from the creative tab and JEI</strong>: the book's <code>creative_tab</code> field pointed at a nonexistent vanilla tab (<code>tools_and_utilities</code>, which doesn't exist in this Minecraft version — the real one is simply <code>tools</code>). Fixed, and the book is now also explicitly registered in the mod's own Adventure tab to guarantee it shows up.</li>
</ul>
