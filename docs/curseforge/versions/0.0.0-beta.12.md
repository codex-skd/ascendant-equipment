<h2>v0.0.0-beta.12 - Advancement Predicate Syntax Fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Advancement Predicates</strong>: Corrected NeoForge 26.2 entity predicate syntax in <code>ascent.json</code>, <code>summit.json</code>, and <code>pinnacle.json</code>. Changed invalid <code>type_specific</code> and <code>type</code> wrappers to <code>sub_predicate</code> to properly reference both custom and vanilla entity predicates. The old Apotheosis 26.1.2 syntax was incompatible with NeoForge 26.2 predicate parsing.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Advancement data files now correctly parse without data file errors on server startup.</li>
<li>Entity predicates <code>is_invader</code> (custom), <code>minecraft:wither</code>, and <code>minecraft:ender_dragon</code> are now properly recognized.</li>
<li>Progression advancements will now function as intended for tracking player progression.</li>
</ul>

<blockquote>
<strong>Note:</strong> This release resolves JSON parsing errors that prevented advancement progression tracking from functioning. All players should update to ensure proper advancement detection and item rarity classification.
</blockquote>
