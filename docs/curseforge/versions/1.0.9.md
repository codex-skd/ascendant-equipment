<h2>v1.0.9 - Missing Tooltip Translations</h2>

<li><strong>Enchantment gem/affix bonuses</strong>: the description line for any gem or affix that grants or boosts an enchantment showed a raw untranslated key (<code>bonus.ascendant_equipment:enchantment.desc...</code>) instead of readable text.</li>
<li><strong>Omnetic gem/affix bonuses</strong> (tool-tier "effectiveness against all blocks" gems, e.g. Gem of the Molten Breach): the tool tier name (Iron/Diamond/Netherite) leaked as a raw key instead of its translated name.</li>
</ul>
